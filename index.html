Quick start — 3 steps

  1. Settings & Deploy: add your own Google OAuth Client ID + Client Secret (free, 5 min — steps in GLOBAL_SETUP.md), Save to my vault, then connect below.
  2. Drive Videos: Connect Google → Load videos → Preview → “Use this video”.
  3. Compose & Publish: title/caption/tags are auto-suggested, tick platforms, Publish. Or say: krishna! muse publish latest video to all

📅 Bulk Schedule — 10 Shorts/day (YouTube scheduled publishing)

Uploads every unpublished tracker row (in SL order) to YouTube as private with a scheduled release: 10 per day at 7:00, 8:30, 10:00, 11:30 AM, 1:00, 2:30, 4:00, 5:30, 7:00, 8:30 PM US Eastern, starting today. YouTube itself releases each video at its slot — no browser needs to stay open. Titles/captions/tags come from the tracker sheet exactly as written. Each scheduled row is marked Published YES with its link. If YouTube's daily API quota is reached, the run stops cleanly — press the button again after the quota resets (13:30 IST) and it resumes where it left off.

Publish to

Direct from this static app: YouTube (full browser upload) and Facebook / Instagram (Meta Graph API, needs Meta settings). X, TikTok, LinkedIn go through your Muse Bridge webhook (Make / n8n / Zapier / Supabase Function) because those APIs need a secret backend — a static GitHub Pages site must never hold secret keys. If no webhook is set, those jobs are prepared as a Muse Job you can paste to Krishna in Muse chat.

✦ Talk to Muse — Command Center

Type or speak a command starting with krishna! muse. Examples:
krishna! muse publish latest video to all • krishna! muse upload this to youtube and instagram • krishna! muse refresh drive • krishna! muse add latest to queue • krishna! muse export history

Voice uses your browser mic (Chrome works best). Wake phrase inside the app is “krishna muse”.

Muse Bridge

Two ways this app talks to Muse (Krishna):

  1. Copy Job: any publish action can generate a structured Muse Job. Paste it in your Muse chat / WhatsApp and Krishna picks it up.
  2. Webhook: set a Muse Bridge URL in Settings (Make/n8n webhook). Jobs are POSTed there instantly — that webhook can notify Muse, upload to X/TikTok/LinkedIn, and log to your sheet.

Deploy trigger

In Muse chat, your deploy phrase is saved as: krishna! muse deploy — when you send that to Krishna, the latest version of this app is packaged for GitHub Pages. Inside this app, type the same phrase to open Deploy help.

Deploy on GitHub Pages — in 4 steps

  1. Create a new GitHub repo, e.g. social-publisher (your own GitHub username).
  2. Upload index.html + README.md from this repo → Commit.
  3. Repo → Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.
  4. Your app goes live at https://YOUR-USERNAME.github.io/social-publisher/ — then add that exact origin as an Authorized JavaScript origin, and the vault function URL as the Authorized redirect URI, in your Google OAuth client (GLOBAL_SETUP.md).
Say krishna! muse deploy to Krishna in Muse chat whenever you want a fresh zip of the latest version packaged for upload.

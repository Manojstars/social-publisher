Publish to

Direct from this static app: YouTube (full browser upload) and Facebook / Instagram (Meta Graph API, needs Meta settings). X, TikTok, LinkedIn go through your Muse Bridge webhook (Make / n8n / Zapier / Supabase Function) because those APIs need a secret backend — a static GitHub Pages site must never hold secret keys. ✦ Talk to Muse — Command Center

Type or speak a command starting with krishna! muse. Examples:
krishna! muse publish latest video to all • krishna! muse upload this to youtube and instagram • krishna! muse refresh drive • krishna! muse add latest to queue • krishna! muse export history

Voice uses your browser mic (Chrome works best). Wake phrase inside the app is “krishna muse”.

Muse Bridge

Two ways this app talks to Muse (Krishna):

  1. Copy Job: any publish action can generate a structured Muse Job. Paste it in your Muse chat / WhatsApp and Krishna picks it up.
  2. Webhook: set a Muse Bridge URL in Settings (Make/n8n webhook). Jobs are POSTed there instantly — that webhook can notify Muse, upload to X/TikTok/LinkedIn, and log to your sheet.

Deploy trigger

In Muse chat, your deploy phrase is saved as: krishna! muse deploy — when you send that to Krishna, the latest version of this app is packaged for GitHub Pages. Inside this app, type the same phrase to open Deploy help.

Two separate sign-ins are supported: Drive videos are read with the Drive account token, YouTube uploads use the YouTube account token. You may also use the same Client ID in both boxes if one project is shared — the accounts you pick at sign-in are what matter.
Tracker columns: A = SL NO, B = Title, C = Link, D = Published. Before every upload the app checks this sheet and blocks duplicates (Published = YES). After a confirmed upload it writes the YouTube link and sets Published = YES automatically.

Never paste a Google client secret, Meta app secret, or any service_role key here or in GitHub. This app uses only public client IDs + user tokens in the browser.

Deploy on GitHub Pages — in 4 steps

  1. Create a new GitHub repo, e.g. social-publisher (username: manojstars).
  2. Upload index.html + README.md from the zip Krishna gives you → Commit.
  3. Repo → Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.
  4. Your app goes live at https://manojstars.github.io/social-publisher/ — then add that exact URL as an Authorized JavaScript origin in your Google OAuth client (SETUP.md).
Say krishna! muse deploy to Krishna in Muse chat whenever you want a fresh zip of the latest version packaged for upload.
